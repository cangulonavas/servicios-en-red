# Servicios en red

El módulo de Servicios en Red del segundo curso del ciclo formativo de SMR (Sistemas Microinformáticos y Redes) consiste en capacitar al alumno para instalar, configurar y mantener los servicios fundamentales de una red de datos, garantizando que los equipos de una organización puedan comunicarse entre sí y acceder a recursos de internet de forma correcta y segura. Aprendes a transformar un sistema operativo en un servidor funcional.
A continuación se detalla el contenido que se va a impartir estructurado según sus temas:

**Fundamentos y Entorno de Trabajo**

T1. Virtualización y repaso de redes: Preparación del entorno de prácticas mediante máquinas virtuales y consolidación de conceptos clave de direccionamiento y topologías de red.

**Servicios de Configuración y Resolución de Nombres**

T2. DHCP (Configuración de direcciones IP): Automatización de la asignación de direcciones IP y parámetros de red a los clientes de la malla.

T3. DNS (Sistema de nombres de dominio): Traducción de nombres de dominio comprensibles para los humanos en direcciones IP para la correcta navegación.

**Acceso y Publicación de Información**

T4. SSH (Acceso remoto): Gestión y administración a distancia de servidores y equipos de red de forma cifrada y segura.

T5. HTTP (Servicios web): Despliegue, configuración y mantenimiento de servidores web para alojar páginas y aplicaciones.

**Interconexión, Archivos y Mensajería**

T6. Proxy (Interconexión de redes): Control, filtrado y optimización del tráfico de datos entre la red local interna y las redes públicas (Internet).

T7. FTP (Transferencia de ficheros): Configuración de servidores para el almacenamiento, subida y descarga de archivos en la red de forma eficiente.

T8. Servicios de correo: Implementación de la arquitectura necesaria para el envío y recepción de mensajes electrónicos corporativos.
